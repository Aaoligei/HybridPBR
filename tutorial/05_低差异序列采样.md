# 低差异序列采样

## 本章目标

深入理解低差异序列（Halton、Sobol等）的原理与实现，改进光线追踪的采样质量。

## 6.1 为什么需要低差异序列？

### 6.1.1 随机采样的问题

```
真正的随机采样：
┌─────────────────────────────────────────────┐
│  问题1：聚集                               │
│  ┌─────────────┐                           │
│  │  ● ●        │  有些区域被多次采样       │
│  │    ● ●●     │  有些区域从未被采样       │
│  │        ●    │  → 浪费样本，收敛慢       │
│  │  ●      ●   │                           │
│  └─────────────┘                           │
│                                            │
│  问题2：不均匀的误差分布                   │
│  聚集区域：样本多，误差小                  │
│  空白区域：样本少，误差大                  │
│  → 图像上出现斑块状噪声                    │
└─────────────────────────────────────────────┘
```

### 6.1.2 低差异序列的优势

```
低差异序列采样：
┌─────────────────────────────────────────────┐
│  特点：均匀分布                             │
│  ┌─────────────┐                           │
│  │  ●   ●   ●  │  每个区域都被覆盖         │
│  │    ●   ●    │  没有聚集或空白           │
│  │  ●   ●   ●  │  → 样本利用率高           │
│  │    ●   ●    │  → 收敛更快               │
│  └─────────────┘                           │
│                                            │
│  数学度量：差异值（Discrepancy）           │
│  随机序列：高差异                          │
│  低差异序列：低差异                        │
└─────────────────────────────────────────────┘
```

### 6.1.3 收敛速度对比

```
采样误差 vs 样本数量：

随机采样：误差 ∝ 1/√N
低差异序列：误差 ∝ 1/N（理想情况下）

例子：要达到1%的误差
- 随机采样：需要约10000个样本
- 低差异序列：需要约100个样本

差距巨大！
```

## 6.2 Halton序列

### 6.2.1 原理

Halton序列基于"基数反转"：

```
以基数为2的Halton序列为例：

步骤1：将整数写成二进制
  1 = 1₂
  2 = 10₂
  3 = 11₂
  4 = 100₂
  5 = 101₂

步骤2：反转二进制并在小数点后放置
  1 → 0.1₂ = 0.5
  2 → 0.01₂ = 0.25
  3 → 0.11₂ = 0.75
  4 → 0.001₂ = 0.125
  5 → 0.101₂ = 0.625

结果序列：0.5, 0.25, 0.75, 0.125, 0.625, ...

这些点在[0,1]区间均匀分布！
```

### 6.2.2 通用算法

```cpp
// C++实现
float Halton(int index, int base) {
    float result = 0.0f;
    float f = 1.0f / base;
    int i = index;
    
    while (i > 0) {
        result += f * (i % base);
        i /= base;
        f /= base;
    }
    
    return result;
}

// 生成2D Halton点
glm::vec2 Halton2D(int index) {
    // 使用不同的基数避免相关性
    // 常用组合：(2,3), (2,5), (3,5)
    return glm::vec2(
        Halton(index, 2),  // 基数2
        Halton(index, 3)   // 基数3
    );
}
```

### 6.2.3 GLSL实现

```glsl
// GLSL实现（用于着色器）
float Halton(int index, int base) {
    float result = 0.0;
    float f = 1.0 / float(base);
    int i = index;
    
    // 使用循环展开优化性能
    for (int j = 0; j < 8; j++) {  // 最多处理8位
        if (i <= 0) break;
        result += f * float(i % base);
        i = i / base;
        f = f / float(base);
    }
    
    return result;
}

// 使用示例
vec2 jitter = vec2(
    Halton(frameNumber % 64 + 1, 2) - 0.5,
    Halton(frameNumber % 64 + 1, 3) - 0.5
);
```

## 6.3 Sobol序列

### 6.3.1 原理

Sobol序列使用方向数和位运算：

```
Sobol序列的核心：
┌─────────────────────────────────────────────┐
│  每个维度有一个方向数序列                    │
│  使用位异或操作生成新点                      │
│                                            │
│  方向数：v₀, v₁, v₂, ...                   │
│                                            │
│  第n个Sobol点 = vₖ₁ ⊕ vₖ₂ ⊕ vₖ₃ ⊕ ...     │
│  其中k₁, k₂, k₃是n的二进制表示中为1的位置  │
└─────────────────────────────────────────────┘
```

### 6.3.2 方向数

Sobol序列需要预计算的方向数：

```cpp

    0x80008000u, 0xc000c000u, 0xa000a000u, 0xf000f000u,
    0x88008800u, 0xcc00cc00u, 0xaa00aa00u, 0xff00ff00u,
    0x80808080u, 0xc0c0c0c0u, 0xa0a0a0a0u, 0xf0f0f0f0u,
    0x88888888u, 0xccccccccu, 0xaaaaaaaau, 0xffffffffu
};
```

### 6.3.3 GLSL实现

```glsl
// Sobol序列实现

// 方向数作为常量数组（或通过SSBO传入）
const uint sobolV0[32] = uint[](
    0x80000000u, 0xc0000000u, 0xa0000000u, 0xf0000000u,
    0x88000000u, 0xcc000000u, 0xaa000000u, 0xff000000u,
    0x80800000u, 0xc0c00000u, 0xa0a00000u, 0xf0f00000u,
    0x88880000u, 0xcccc0000u, 0xaaaa0000u, 0xffff0000u,
    0x80008000u, 0xc000c000u, 0xa000a000u, 0xf000f000u,
    0x88008800u, 0xcc00cc00u, 0xaa00aa00u, 0xff00ff00u,
    0x80808080u, 0xc0c0c0c0u, 0xa0a0a0a0u, 0xf0f0f0f0u,
    0x88888888u, 0xccccccccu, 0xaaaaaaaau, 0xffffffffu
);

const uint sobolV1[32] = uint[](
    0x80000000u, 0xc0000000u, 0x60000000u, 0x90000000u,
    0x8c000000u, 0xc6000000u, 0x69000000u, 0x9f000000u,
    0x80800000u, 0xc0400000u, 0x60200000u, 0x90100000u,
    0x8c080000u, 0xc6040000u, 0x69020000u, 0x9f010000u,
    0x80008000u, 0xc0004000u, 0x60002000u, 0x90001000u,
    0x8c000800u, 0xc6000400u, 0x69000200u, 0x9f000100u,
    0x80800080u, 0xc0400040u, 0x60200020u, 0x90100010u,
    0x8c080008u, 0xc6040004u, 0x69020002u, 0x9f010001u
);

float Sobol(uint index, uint dimension) {
    uint result = 0u;
    uint i = index;
    uint bit = 0u;
    
    // 遍历index的每一位
    while (i > 0u) {
        // 找到最低的设置位
        if ((i & 1u) != 0u) {
            if (dimension == 0u) {
                result ^= sobolV0[bit];
            } else {
                result ^= sobolV1[bit];
            }
        }
        i >>= 1u;
        bit++;
    }
    
    // 归一化到[0,1)
    return float(result) / 4294967296.0;
}

// 生成2D Sobol点
vec2 Sobol2D(uint index) {
    return vec2(
        Sobol(index, 0u),
        Sobol(index, 1u)
    );
}
```

### 6.3.4 优化的Sobol实现

使用查找表加速：

```glsl
// 预计算256个Sobol点，存储在纹理或UBO中
layout(std140, binding = 10) uniform SobolData {
    vec4 sobolPoints[64];  // 存储256个点（每个vec4存储2个点）
};

vec2 GetSobolPoint(uint index) {
    // 使用位操作从预计算数据中获取
    uint vecIndex = index / 2u;
    uint component = index % 2u;
    
    if (component == 0u) {
        return sobolPoints[vecIndex].xy;
    } else {
        return sobolPoints[vecIndex].zw;
    }
}
```

## 6.4 采样策略集成

### 6.4.1 像素内抖动

用于TAA：

```glsl
// 在光线生成中使用
vec2 GetPixelJitter(uint frameNumber) {
    // 方法1：Halton
    vec2 halton = vec2(
        Halton(frameNumber % 64 + 1, 2),
        Halton(frameNumber % 64 + 1, 3)
    );
    
    // 方法2：Sobol
    vec2 sobol = Sobol2D(frameNumber % 256);
    
    // 转换到[-0.5, 0.5]范围
    return halton - 0.5;  // 或 sobol - 0.5
}
```

### 6.4.2 光线方向采样

用于路径追踪中的方向采样：

```glsl
// 余弦加权半球采样 + Sobol
vec3 SampleCosineHemisphereSobol(vec3 N, uint sampleIndex, uint bounce) {
    // 组合像素索引、样本索引、弹射次数生成唯一索引
    uint index = pixelIndex + sampleIndex * 4096 + bounce * 256;
    
    vec2 u = Sobol2D(index);
    
    // 余弦加权映射
    float r = sqrt(u.x);
    float phi = 2.0 * PI * u.y;
    
    vec3 L = vec3(r * cos(phi), r * sin(phi), sqrt(1.0 - u.x));
    
    // 转换到世界空间
    vec3 T, B;
    BuildOrthonormalBasis(N, T, B);
    return T * L.x + B * L.y + N * L.z;
}
```

### 6.4.3 随机数生成器改进

将简单的随机数生成器替换为基于Sobol的版本：

```glsl
// 原来的简单随机
float RandomFloat(inout uint seed) {
    seed = WangHash(seed);
    return float(seed) * (1.0 / 4294967296.0);
}

// 改进：使用Sobol + 扰乱
float RandomFloatSobol(inout uint seed, uint dimension) {
    // 使用Sobol作为基础
    float sobolValue = Sobol(seed % 256, dimension);
    
    // 用简单的hash扰乱，增加"随机性"
    uint scramble = WangHash(seed);
    float scrambled = fract(sobolValue + float(scramble) / 4294967296.0);
    
    seed++;
    return scrambled;
}
```

## 6.5 多维采样

### 6.5.1 采样维度分析

路径追踪需要多个独立的随机维度：

```
┌─────────────────────────────────────────────────────────────┐
│  采样维度分配示例                                           │
├─────────────────────────────────────────────────────────────┤
│  维度 0-1: 像素内位置（TAA抖动）                           │
│  维度 2-3: 第一跳光线方向                                   │
│  维度 4-5: 第二跳光线方向                                   │
│  维度 6-7: 第三跳光线方向                                   │
│  维度 8:   光源选择                                         │
│  维度 9-10: 光源采样位置                                    │
│  ...                                                        │
└─────────────────────────────────────────────────────────────┘
```

### 6.5.2 多维Sobol采样器

```glsl
// 多维Sobol采样器
struct SobolSampler {
    uint baseIndex;      // 像素索引
    uint frameIndex;     // 帧索引
    uint sampleIndex;    // 当前样本索引
    uint dimension;      // 当前维度
};

void InitSobolSampler(inout SobolSampler s, uint pixelIndex, uint frameIndex, uint sampleIndex) {
    s.baseIndex = pixelIndex;
    s.frameIndex = frameIndex;
    s.sampleIndex = sampleIndex;
    s.dimension = 0;
}

float NextFloat(inout SobolSampler s) {
    // 组合所有索引
    uint index = s.baseIndex + s.frameIndex * 262144 + s.sampleIndex * 4096;
    
    float value = Sobol(index, s.dimension);
    s.dimension++;
    
    return value;
}

vec2 NextVec2(inout SobolSampler s) {
    return vec2(NextFloat(s), NextFloat(s));
}

vec3 NextVec3(inout SobolSampler s) {
    return vec3(NextFloat(s), NextFloat(s), NextFloat(s));
}
```

class SobolTable {

// 使用位运算代替取模
uint fastMod(uint value, uint modulus) {
    // 如果modulus是2的幂，可以用位与
    return value & (modulus - 1u);
}

// Morton码编码（用于空间分布）
uint mortonEncode(uint x, uint y) {
    uint result = 0u;
    for (int i = 0; i < 16; i++) {
        result |= ((x & (1u << i)) << i) | ((y & (1u << i)) << (i + 1));
    }
    return result;
}
