# 抗锯齿原理与改进

## 本章目标

理解光线追踪中抗锯齿的原理，实现高质量的时间抗锯齿（TAA），改进采样策略。

---

## 5.1 什么是锯齿（Aliasing）？

### 5.1.1 锯齿的来源

想象你用方格纸画一条斜线：

```
理想直线          像素化后
    /            █░░░░
   /             █░░░░  ← 出现"台阶"
  /              ░█░░░
 /               ░░█░░
/                ░░░█░

这就是锯齿：用离散像素表示连续信号时产生的问题。
```

在光线追踪中，锯齿出现在：

```
┌─────────────────────────────────────────────────────────────┐
│  锯齿类型          │  出现场景          │  视觉表现          │
├─────────────────────────────────────────────────────────────┤
│  几何锯齿          │  物体边缘          │  阶梯状边缘        │
│  纹理锯齿          │  远处的纹理        │  摩尔纹、闪烁      │
│  阴影锯齿          │  阴影边界          │  锯齿状阴影边缘    │
│  高光锯齿          │  高光边缘          │  闪烁的高光        │
└─────────────────────────────────────────────────────────────┘
```

### 5.1.2 奈奎斯特采样定理

```
信号处理告诉我们：

采样频率 ≥ 2 × 最高信号频率

才能完美重建信号。

在图形学中：
- "最高频率"对应最细的细节（如边缘）
- "采样频率"是像素密度
- 如果像素不够密，就会出现锯齿
```

**解决方案**：

```
┌─────────────────────────────────────────────────────────────┐
│  方案一：提高分辨率                                           │
│  ════════════════════                                       │
│  - 增加采样频率                                              │
│  - 问题：计算量太大                                          │
│                                                             │
│  方案二：低通滤波（模糊）                                     │
│  ══════════════════════════                                 │
│  - 移除高频信息                                              │
│  - 问题：图像变模糊                                          │
│                                                             │
│  方案三：超采样（SSAA/MSAA）                                  │
│  ════════════════════════                                   │
│  - 每像素多次采样                                            │
│  - 问题：性能开销大                                          │
│                                                             │
│  方案四：时间抗锯齿（TAA）★推荐★                              │
│  ════════════════════════                                   │
│  - 利用多帧信息                                              │
│  - 高效且效果好                                              │
└─────────────────────────────────────────────────────────────┘
```

## 5.2 当前实现分析

### 5.2.1 当前代码

在`ray_generation.comp`中：

```glsl
// 添加随机性用于抗锯齿
if (frameNumber > 0) {
    vec2 jitter = vec2(
        float((pixelIndex * 1973 + frameNumber) & 0xFF) / 255.0 - 0.5,
        float((pixelIndex * 9277 + frameNumber) & 0xFF) / 255.0 - 0.5
    ) / float(width);
    
    uv += jitter;
}
```

### 5.2.2 问题分析

**问题一：随机数质量差**

```
当前使用的哈希：
(pixelIndex * 1973 + frameNumber) & 0xFF

这只取了低8位，周期只有256
导致抖动模式很快重复
```

**问题二：抖动幅度太小**

```
jitter范围：[-0.5/width, 0.5/width]

假设width=1920：
jitter范围 ≈ [-0.00026, 0.00026]

这个范围太小，效果有限
```

**问题三：没有子像素抖动**

```
正确的TAA抖动应该覆盖整个像素范围：
jitter范围 = [-0.5, 0.5] 像素

当前代码除以了width，导致范围太小
```

## 5.3 时间抗锯齿（TAA）原理

### 5.3.1 核心思想

TAA的核心是"把超采样分散到时间上"：

```
传统超采样（4x SSAA）：
每帧每像素采样4次

    帧N
    ┌───┐
    │●●●│  ← 4个采样点
    │●●●│
    └───┘

TAA（等效4x）：
每帧每像素采样1次，连续4帧覆盖不同位置

帧N    帧N+1  帧N+2  帧N+3
┌─┐    ┌─┐    ┌─┐    ┌─┐
│●│    │ ●│    │  ●│    │   │
└─┘    └─┘    └─┘    └─┘

4帧累积后 = 4次采样的效果
```

### 5.3.2 抖动模式

需要在像素内均匀分布采样点：

```
Halton序列（低差异序列）示例：
┌─────────────────┐
│  帧0: (0.5, 0.33)  ●         │
│  帧1: (0.25, 0.67)    ●      │
│  帧2: (0.75, 0.11) ●         │
│  帧3: (0.125, 0.44)   ●      │
│  ...                         │
└─────────────────┘

这些点均匀分布在像素内，没有聚集
```

### 5.3.3 TAA与降噪的关系

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  TAA实际上是一种"时域降噪"！                                 │
│                                                             │
│  降噪目标：减少蒙特卡洛噪声                                  │
│  TAA目标：减少几何锯齿                                      │
│                                                             │
│  共同点：                                                   │
│  - 都利用历史帧                                             │
│  - 都需要运动向量                                           │
│  - 都需要有效性检测                                         │
│                                                             │
│  因此，TAA和时域降噪可以合并实现！                           │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 5.4 改进抖动策略

### 5.4.1 修正抖动范围

```glsl
// 改进的光线生成

// 正确的抖动：范围是[-0.5, 0.5]像素
vec2 jitter = vec2(
    float((pixelIndex * 1973 + frameNumber) & 0xFF) / 255.0 - 0.5,
    float((pixelIndex * 9277 + frameNumber) & 0xFF) / 255.0 - 0.5
);

// 转换到UV偏移（注意：除以分辨率是在这里）
vec2 jitterUV = jitter / vec2(width, height);

// 应用到UV
uv += jitterUV;
```

### 5.4.2 使用Halton序列

Halton序列是一种低差异序列，生成均匀分布的点：

```glsl
// Halton序列生成函数
float Halton(int index, int base) {
    float result = 0.0;
    float f = 1.0 / float(base);
    int i = index;
    
    while (i > 0) {
        result += f * float(i % base);
        i = i / base;
        f = f / float(base);
    }
    
    return result;
}

// 获取帧抖动
vec2 GetJitter(int frameNumber) {
    // 使用Halton(2,3)序列
    // 这会产生均匀分布在[0,1)范围内的点
    float x = Halton(frameNumber % 16 + 1, 2);
    float y = Halton(frameNumber % 16 + 1, 3);
    
    // 转换到[-0.5, 0.5]范围
    return vec2(x - 0.5, y - 0.5);
}
```

### 5.4.3 使用Sobol序列

Sobol序列质量更高，但实现稍复杂：

```glsl
// Sobol序列预计算表（在着色器中硬编码或作为uniform传入）
const uint sobolMatrix[32] = uint[](
    0x80000000u, 0xc0000000u, 0xa0000000u, 0xf0000000u,
    0x88000000u, 0xcc000000u, 0xaa000000u, 0xff000000u,
    // ... 完整的Sobol矩阵
    // 可以查表获取
);

float Sobol(uint index, uint dimension) {
    uint result = 0u;
    uint i = index;
    
    while (i > 0u) {
        uint j = findLSB(i);  // 找到最低设置位
        result ^= sobolMatrix[dimension * 32 + j];
        i &= i - 1u;  // 清除最低设置位
    }
    
    return float(result) / 4294967296.0;  // 2^32
}

vec2 GetSobolJitter(uint frameNumber, uint pixelIndex) {
    // 组合像素索引和帧号，生成唯一序列号
    uint seed = pixelIndex + frameNumber * 262144u;
    
    float x = Sobol(seed, 0);
    float y = Sobol(seed, 1);
    
    return vec2(x - 0.5, y - 0.5);
}
```

## 5.5 抖动与运动向量的配合

### 5.5.1 抖动的传播

关键问题：抖动会影响运动向量的计算！

```
问题：
帧N: 像素中心在 (x+0.3, y+0.2) 抖动
帧N+1: 像素中心在 (x-0.1, y+0.4) 抖动

运动向量计算时，需要考虑抖动的差异！
```

### 5.5.2 抖动补偿

```glsl
// 存储当前帧和上一帧的抖动值
uniform vec2 currentJitter;   // 当前帧抖动
uniform vec2 previousJitter;  // 上一帧抖动

// 计算运动向量时需要补偿抖动
vec2 calculateMotionWithJitter(vec2 baseMotion, vec2 currentJitter, vec2 previousJitter) {
    // 基础运动向量（物体/相机运动）
    vec2 motion = baseMotion;
    
    // 减去抖动差异
    // 因为抖动是我们主动添加的，不应该被视为运动
    motion += previousJitter;  // 上一帧的抖动
    motion -= currentJitter;   // 当前帧的抖动
    
    return motion;
}
```

### 5.5.3 完整的光线生成代码

```glsl
// ray_generation.comp 改进版

#version 460 core
layout(local_size_x = 16, local_size_y = 16) in;

layout(std140, binding = 8) uniform CameraData {
    mat4 view;
    mat4 projection;
    vec3 viewPos;
};

struct Ray {
    vec3 origin;
    vec3 direction;
    float tMin;
    float tMax;
};

layout(std430, binding = 0) buffer RayBuffer { Ray rays[]; };
layout(std430, binding = 1) buffer OutputBuffer { vec4 outputPixels[]; };

uniform uint width;
uniform uint height;
uniform uint frameNumber;
uniform vec2 jitter;  // 从C++传入的抖动值

float Halton(int index, int base) {
    float result = 0.0;
    float f = 1.0 / float(base);
    int i = index;
    
    while (i > 0) {
        result += f * float(i % base);
        i = i / base;
        f = f / float(base);
    }
    
    return result;
}

void main() {
    uint x = gl_GlobalInvocationID.x;
    uint y = gl_GlobalInvocationID.y;
    
    if (x >= width || y >= height) return;
    
    uint pixelIndex = y * width + x;
    
    // 计算像素中心UV
    vec2 uv = vec2(float(x) + 0.5, float(y) + 0.5) / vec2(width, height);
    
    // 应用抖动（抖动已经是[-0.5, 0.5]范围）
    vec2 jitteredUV = uv + jitter / vec2(width, height);
    
    // 转换到NDC
    vec2 ndc = jitteredUV * 2.0 - 1.0;
    
    // 构建光线方向
    vec4 target = projection * vec4(ndc.x, ndc.y, 1.0, 1.0);
    vec3 rayDirView = normalize(target.xyz / target.w);
    vec3 rayDirWorld = (view * vec4(rayDirView, 0.0)).xyz;
    
    // 存储光线
    rays[pixelIndex].origin = viewPos;
    rays[pixelIndex].direction = normalize(rayDirWorld);
    rays[pixelIndex].tMin = 0.001;
    rays[pixelIndex].tMax = 10000.0;
    
    // 初始化输出（仅第一帧）
    if (frameNumber == 0) {
        outputPixels[pixelIndex] = vec4(0.0);
    }
}
```

## 5.6 完整TAA实现

### 5.6.1 TAA着色器

```glsl
// taa_resolve.comp

#version 460 core
layout(local_size_x = 16, local_size_y = 16) in;

layout(binding = 0) uniform sampler2D currentColor;
layout(binding = 1) uniform sampler2D historyColor;
layout(binding = 2) uniform sampler2D motionVectors;
layout(binding = 3) uniform sampler2D currentDepth;
layout(binding = 4) uniform sampler2D historyDepth;

layout(binding = 0, rgba16f) uniform image2D outputImage;

uniform int width;
uniform int height;
uniform vec2 currentJitter;
uniform vec2 previousJitter;

// 邻域裁剪
vec3 clipAABB(vec3 history, vec3 minColor, vec3 maxColor) {
    // AABB裁剪算法
    vec3 center = 0.5 * (maxColor + minColor);
    vec3 extents = 0.5 * (maxColor - minColor);
    
    vec3 displacement = history - center;
    vec3 absDisplacement = abs(displacement);
    
    vec3 ts = extents / (absDisplacement + 0.0001);
    float t = min(min(ts.x, ts.y), ts.z);
    t = min(t, 1.0);
    
    return center + displacement * t;
}

void main() {
    ivec2 coords = ivec2(gl_GlobalInvocationID.xy);
    if (coords.x >= width || coords.y >= height) return;
    
    vec2 texelSize = 1.0 / vec2(width, height);
    vec2 uv = (vec2(coords) + 0.5) * texelSize;
    
    // 当前颜色
    vec3 current = texelFetch(currentColor, coords, 0).rgb;
    
    // 计算邻域范围
    vec3 minColor = vec3(1e9);
    vec3 maxColor = vec3(-1e9);
    
    for (int y = -1; y <= 1; y++) {
        for (int x = -1; x <= 1; x++) {
            vec3 neighbor = texelFetch(currentColor, 
                clamp(coords + ivec2(x, y), ivec2(0), ivec2(width-1, height-1)), 0).rgb;
            minColor = min(minColor, neighbor);
            maxColor = max(maxColor, neighbor);
        }
    }
    
    // 读取运动向量
    vec2 motion = texelFetch(motionVectors, coords, 0).rg;
    
    // 补偿抖动
    motion += previousJitter;
    motion -= currentJitter;
    
    // 计算历史采样位置
    vec2 historyUV = uv + motion * texelSize;
    
    // 有效性检测
    bool validHistory = all(greaterThanEqual(historyUV, vec2(0.0))) &&
                        all(lessThan(historyUV, vec2(1.0)));
    
    // 深度检测
    if (validHistory) {
        float currentDepth = texelFetch(currentDepth, coords, 0).r;
        float historyDepth = texture(historyDepth, historyUV).r;
        if (abs(currentDepth - historyDepth) > 0.01) {
            validHistory = false;
        }
    }
    
    // 计算最终颜色
    vec3 finalColor;
    float blendFactor = 0.1;  // 新帧权重
    
    if (validHistory) {
        vec3 history = texture(historyColor, historyUV).rgb;
        
        // 邻域裁剪
        history = clipAABB(history, minColor, maxColor);
        
        // 混合
        finalColor = mix(history, current, blendFactor);
    } else {
        // 无有效历史，直接使用当前颜色
        finalColor = current;
    }
    
    imageStore(outputImage, coords, vec4(finalColor, 1.0));
}
```

## 5.7 进阶：方差估计与自适应混合

### 5.7.1 动态调整混合权重

根据噪声水平动态调整历史权重：

```glsl
// 计算局部方差
float calculateVariance(vec3 colors[9]) {
    vec3 mean = vec3(0.0);
    for (int i = 0; i < 9; i++) {
        mean += colors[i];
    }
    mean /= 9.0;
    
    float variance = 0.0;
    for (int i = 0; i < 9; i++) {
        variance += dot(colors[i] - mean, colors[i] - mean);
    }
    variance /= 9.0;
    
    return variance;
}

// 根据方差调整混合权重
float getAdaptiveBlendFactor(float variance) {
    // 高方差（噪声大）→ 更信任历史
    // 低方差（噪声小）→ 更信任当前
    float minBlend = 0.05;
    float maxBlend = 0.2;
    
    // 方差映射到混合权重
    float t = clamp(variance * 10.0, 0.0, 1.0);
    return mix(maxBlend, minBlend, t);
}
```

### 5.7.2 颜色带宽限制

减少颜色差异的感知：

```glsl
// 在YCoCg颜色空间进行操作
vec3 RGBToYCoCg(vec3 rgb) {
    float y = 0.25 * rgb.r + 0.5 * rgb.g + 0.25 * rgb.b;
    float co = 0.5 * rgb.r - 0.5 * rgb.b;
    float cg = -0.25 * rgb.r + 0.5 * rgb.g - 0.25 * rgb.b;
    return vec3(y, co, cg);
}

vec3 YCoCgToRGB(vec3 ycocg) {
    float r = ycocg.x + ycocg.y - ycocg.z;
    float g = ycocg.x + ycocg.z;
    float b = ycocg.x - ycocg.y - ycocg.z;
    return vec3(r, g, b);
}

// 在YCoCg空间进行邻域裁剪
vec3 historyYCoCg = RGBToYCoCg(history);
vec3 minYCoCg = RGBToYCoCg(minColor);
vec3 maxYCoCg = RGBToYCoCg(maxColor);
historyYCoCg = clamp(historyYCoCg, minYCoCg, maxYCoCg);
history = YCoCgToRGB(historyYCoCg);
```

## 5.9 常见问题

### 问题1：图像模糊

**原因**：混合权重过低，历史累积过多

**解决**：
```glsl
float blendFactor = 0.15;  // 增大新帧权重
```

### 问题2：闪烁

**原因**：历史频繁失效，或有效性检测太严格

**解决**：
- 放宽邻域裁剪的范围
- 使用方差估计动态调整

### 问题3：运动物体拖影

**原因**：运动向量不准确

**解决**：
- 检查运动向量计算
- 在高速运动区域降低历史权重
