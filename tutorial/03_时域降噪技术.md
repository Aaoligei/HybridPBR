# 时域降噪技术

## 本章目标

理解时域降噪的原理，实现基于运动向量的历史帧重投影，解决闪烁和鬼影问题。

---

## 4.1 什么是时域降噪？

### 4.1.1 直观理解

想象你在看一段视频，每一帧都充满了噪点：

```
帧1    帧2    帧3    帧4
░░▓░   ▓░░▓   ░▓░░   ▓░▓░
░▓░▓   ░░▓░   ▓░░░   ░░▓░
▓░░░   ░▓░░   ░░▓▓   ░▓░░
░░▓▓   ▓░░▓   ▓▓░░   ▓░░▓

每一帧噪声分布不同，但都代表同一个场景。
```

**关键观察**：虽然每帧都有噪声，但噪声是随机的，平均后会相互抵消！

```
四帧平均：
(░░▓░ + ▓░░▓ + ░▓░░ + ▓░▓░) / 4
≈ "真实值"

数学原理：
噪声 ≈ 随机变量，均值为0
N帧平均后，噪声方差降为原来的 1/N
```

### 4.1.2 时域降噪 vs 空域降噪

```
┌─────────────────────────────────────────────────────────────┐
│                    对比                                      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  空域降噪（双边滤波）         时域降噪                        │
│  ───────────────────         ────────                       │
│  在单帧内操作                 利用多帧信息                    │
│  模糊像素邻域                 累积历史帧                      │
│  可能损失细节                 保留细节                        │
│  边缘保护复杂                 天然保护边缘                    │
│  实时性好                     需要额外内存                    │
│                                                             │
│  最佳实践：两者结合！                                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 4.2 简单时域累积及其问题

### 4.2.1 当前实现分析

当前项目在`path_tracing.comp`中实现了简单的时域累积：

```glsl
// 当前代码（简化）
if (frameNumber > 0) {
    vec3 history = accumulationPixels[pixelIndex].rgb;
    float weight = 1.0 / float(frameNumber + 1);
    color = mix(history, color, weight);
}
```

这意味着：
```
帧1: color = current
帧2: color = 0.5 * history + 0.5 * current
帧3: color = 0.67 * history + 0.33 * current
帧4: color = 0.75 * history + 0.25 * current
...
```

### 4.2.2 问题一：运动鬼影

**场景**：一个红色球从左向右移动

```
帧1: 球在左边
┌─────────────────────┐
│  ████               │
│  ██████             │
│                     │
└─────────────────────┘

帧2: 球移动到右边
┌─────────────────────┐
│               ████  │
│             ██████  │
│                     │
└─────────────────────┘

简单累积后：
┌─────────────────────┐
│  ░░░░         ████  │  ← 左边出现半透明的"鬼影"
│  ░░░░░░     ██████  │
│                     │
└─────────────────────┘
```

**原因**：没有追踪像素的运动，错误地混合了不同物体的颜色。

### 4.2.3 问题二：闪烁

**场景**：静态场景，但噪声分布每帧不同

```
帧1: 像素(100,100) = 0.8 + 噪声(+0.2) = 1.0
帧2: 像素(100,100) = 0.8 + 噪声(-0.2) = 0.6
帧3: 像素(100,100) = 0.8 + 噪声(+0.1) = 0.9

累积结果在0.6-1.0之间跳动 → 闪烁！
```

## 4.3 运动向量计算

### 4.3.1 运动向量的定义

运动向量表示"当前帧的像素对应上一帧的哪个位置"：

```
运动向量 (motionX, motionY)：

当前帧位置                 上一帧位置
┌─────────────┐           ┌─────────────┐
│             │           │    ◄─────── │  物体向右移动
│       ●─────│───MV────► │         ●   │  运动向量指向左
│             │           │             │
└─────────────┘           └─────────────┘
 当前像素位置              历史采样位置
```

### 4.3.2 计算运动向量

**方法一：速度缓冲区（适用于有速度信息的场景）**

```glsl
// 从G-Buffer读取速度
vec2 motionVector = texelFetch(velocityTexture, coords, 0).rg;
```

**方法二：从位置计算（适用于光追场景）**

```glsl
// 假设你有上一帧和当前帧的位置
vec3 currentPos = texelFetch(currentPositionTexture, coords, 0).rgb;
vec3 previousPos = texelFetch(previousPositionTexture, coords, 0).rgb;

// 转换到屏幕空间
vec4 currentClip = currentProjection * currentView * vec4(currentPos, 1.0);
vec4 previousClip = previousProjection * previousView * vec4(previousPos, 1.0);

vec2 currentNDC = currentClip.xy / currentClip.w;
vec2 previousNDC = previousClip.xy / previousClip.w;

// 运动向量（从当前到上一帧）
vec2 motionVector = previousNDC - currentNDC;

// 转换到像素坐标
motionVector *= 0.5 * vec2(width, height);
```

**方法三：简化版（仅相机运动）**

对于只有相机移动的场景，可以简化计算：

```glsl
// 只考虑相机运动
vec3 worldPos = texelFetch(positionTexture, coords, 0).rgb;

// 当前帧的屏幕坐标
vec4 currentClip = projection * view * vec4(worldPos, 1.0);
vec2 currentScreen = currentClip.xy / currentClip.w;

// 上一帧的屏幕坐标（使用上一帧的相机矩阵）
vec4 previousClip = previousProjection * previousView * vec4(worldPos, 1.0);
vec2 previousScreen = previousClip.xy / previousClip.w;

vec2 motionVector = (previousScreen - currentScreen) * 0.5 * vec2(width, height);
```

### 4.3.3 存储运动向量

创建一个专门的纹理来存储运动向量：

```cpp
// C++代码
auto motionVectorTexture = std::make_shared<Texture>();
motionVectorTexture->Create2D(width, height, GL_RG16F, GL_RG, GL_FLOAT);
```

```glsl
// 着色器中

// 存储
vec2 motionVector = calculateMotionVector(...);
imageStore(motionVectorImage, coords, vec4(motionVector, 0.0, 1.0));
```

## 4.4 历史帧重投影

### 4.4.1 重投影的概念

重投影是将当前帧的像素"投影回"上一帧，找到对应的历史颜色。

```
重投影过程：
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  当前帧                  历史帧                          │
│  ┌──────────┐           ┌──────────┐                   │
│  │    ●     │           │      ●   │                   │
│  │    ↓     │           │      ↑   │                   │
│  │   MV     │           │          │                   │
│  │    ↓     │           │          │                   │
│  │    ◄─────│───────────│──────    │                   │
│  └──────────┘           └──────────┘                   │
│   当前位置             历史采样位置                      │
│                                                         │
│  historyColor = texture(historyTexture, coords + MV)   │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 4.4.2 实现重投影

```glsl
// 时域降噪着色器

uniform sampler2D currentTexture;
uniform sampler2D historyTexture;
uniform sampler2D motionVectorTexture;

uniform int width;
uniform int height;

void main() {
    ivec2 coords = ivec2(gl_GlobalInvocationID.xy);
    
    // 当前颜色
    vec3 currentColor = texelFetch(currentTexture, coords, 0).rgb;
    
    // 读取运动向量
    vec2 motionVector = texelFetch(motionVectorTexture, coords, 0).rg;
    
    // 计算历史采样位置（注意：运动向量指向上一帧）
    vec2 historyCoords = vec2(coords) + motionVector;
    
    // 检查是否在有效范围内
    vec2 texCoords = historyCoords / vec2(width, height);
    bool validHistory = all(greaterThanEqual(texCoords, vec2(0.0))) && 
                        all(lessThanEqual(texCoords, vec2(1.0)));
    
    vec3 finalColor;
    if (validHistory) {
        // 采样历史帧（使用双线性插值）
        vec3 historyColor = texture(historyTexture, texCoords).rgb;
        
        // 混合当前和历史
        float blendFactor = 0.1;  // 新帧的权重
        finalColor = mix(historyColor, currentColor, blendFactor);
    } else {
        finalColor = currentColor;
    }
    
    imageStore(outputImage, coords, vec4(finalColor, 1.0));
}
```

## 4.5 历史有效性检测

### 4.5.1 为什么需要有效性检测？

简单重投影的问题：

```
问题1：物体遮挡
─────────────────
帧1: A物体在前面（可见）
帧2: B物体移动到A前面

当前帧：看到的是B物体
历史帧：该位置是A物体
错误混合 → B物体上出现A的颜色（鬼影）

问题2：物体离开
─────────────────
帧1: 某位置有物体
帧2: 物体移走，该位置变成背景

当前帧：背景颜色
历史帧：物体颜色
错误混合 → 背景上出现物体的残留

问题3：屏幕边缘
─────────────────
运动向量指向屏幕外
无法采样历史帧
```

### 4.5.2 有效性检测方法

**方法一：边界检测**

```glsl
bool isValidHistory(vec2 texCoords) {
    // 检查是否在屏幕范围内
    return all(greaterThanEqual(texCoords, vec2(0.0))) && 
           all(lessThan(texCoords, vec2(1.0)));
}
```

**方法二：颜色相似度检测**

```glsl
bool isValidHistoryColor(vec3 current, vec3 history, float threshold) {
    // 如果颜色差异太大，说明可能是不同物体
    float diff = length(current - history);
    return diff < threshold;
}
```

**方法三：邻域裁剪（Neighborhood Clamping）**

这是工业界常用的方法：

```glsl
vec3 clampHistory(vec3 history, vec3 current, ivec2 coords) {
    // 找到当前像素邻域的颜色范围
    vec3 minColor = current;
    vec3 maxColor = current;
    
    for (int y = -1; y <= 1; y++) {
        for (int x = -1; x <= 1; x++) {
            vec3 neighbor = texelFetch(currentTexture, coords + ivec2(x, y), 0).rgb;
            minColor = min(minColor, neighbor);
            maxColor = max(maxColor, neighbor);
        }
    }
    
    // 将历史颜色裁剪到这个范围内
    return clamp(history, minColor, maxColor);
}
```

**方法四：深度/法线检测**

```glsl
bool isValidHistoryGeometry(ivec2 currentCoords, vec2 historyCoords) {
    // 比较当前帧和历史帧的深度/法线
    float currentDepth = texelFetch(depthTexture, currentCoords, 0).r;
    float historyDepth = texture(historyDepthTexture, historyCoords).r;
    
    vec3 currentNormal = texelFetch(normalTexture, currentCoords, 0).rgb;
    vec3 historyNormal = texture(historyNormalTexture, historyCoords).rgb;
    
    // 如果深度或法线差异太大，说明是不同表面
    float depthDiff = abs(currentDepth - historyDepth);
    float normalDiff = length(currentNormal - historyNormal);
    
    return depthDiff < 0.01 && normalDiff < 0.1;
}
```

### 4.5.3 综合有效性检测

```glsl
float calculateHistoryWeight(vec3 currentColor, vec3 historyColor, 
                             ivec2 coords, vec2 historyTexCoords) {
    float weight = 1.0;
    
    // 1. 边界检测
    if (!isValidHistory(historyTexCoords)) {
        return 0.0;
    }
    
    // 2. 几何检测（如果有G-Buffer）
    float currentDepth = texelFetch(depthTexture, coords, 0).r;
    float historyDepth = texture(historyDepthTexture, historyTexCoords).r;
    if (abs(currentDepth - historyDepth) > 0.02) {
        weight *= 0.1;  // 大幅降低历史权重
    }
    
    // 3. 颜色检测
    float colorDiff = length(currentColor - historyColor);
    if (colorDiff > 0.3) {
        weight *= 0.2;
    }
    
    return weight;
}
```

## 4.6 完整的时域降噪实现

### 4.6.1 数据结构

首先需要管理历史帧数据：

```cpp
// TemporalDenoiser.h

class TemporalDenoiser {
public:
    bool Initialize(uint32_t width, uint32_t height);
    void Resize(uint32_t width, uint32_t height);
    
    // 执行时域降噪
    void Denoise(
        const std::shared_ptr<Texture>& currentColor,
        const std::shared_ptr<Texture>& motionVectors,
        std::shared_ptr<Texture>& output
    );
    
    // 每帧结束前调用，交换历史缓冲区
    void AdvanceFrame();

private:
    // 历史颜色缓冲区
    std::shared_ptr<Texture> historyTexture;
    
    // 历史深度/法线（用于有效性检测）
    std::shared_ptr<Texture> historyDepth;
    std::shared_ptr<Texture> historyNormal;
    
    // 计算着色器
    std::shared_ptr<ComputeShader> temporalShader;
    
    uint32_t width, height;
};
```

### 4.6.2 着色器实现

```glsl
// temporal_denoiser.comp

#version 460 core
layout(local_size_x = 16, local_size_y = 16) in;

// 输入
layout(binding = 0) uniform sampler2D currentColor;
layout(binding = 1) uniform sampler2D historyColor;
layout(binding = 2) uniform sampler2D motionVectors;
layout(binding = 3) uniform sampler2D currentDepth;
layout(binding = 4) uniform sampler2D historyDepth;
layout(binding = 5) uniform sampler2D currentNormal;
layout(binding = 6) uniform sampler2D historyNormal;

// 输出
layout(binding = 0, rgba16f) uniform image2D outputImage;

uniform int width;
uniform int height;
uniform float blendFactor;  // 新帧权重，通常0.05-0.15

// 邻域裁剪
vec3 clampToNeighborhood(vec3 history, vec3 current[9]) {
    vec3 minColor = current[0];
    vec3 maxColor = current[0];
    
    for (int i = 1; i < 9; i++) {
        minColor = min(minColor, current[i]);
        maxColor = max(maxColor, current[i]);
    }
    
    // 扩展范围，允许一定的容忍
    vec3 range = maxColor - minColor;
    minColor -= range * 0.1;
    maxColor += range * 0.1;
    
    return clamp(history, minColor, maxColor);
}

void main() {
    ivec2 coords = ivec2(gl_GlobalInvocationID.xy);
    if (coords.x >= width || coords.y >= height) return;
    
    // 采样当前颜色
    vec3 current = texelFetch(currentColor, coords, 0).rgb;
    
    // 采样当前邻域（用于邻域裁剪）
    vec3 currentNeighborhood[9];
    int idx = 0;
    for (int y = -1; y <= 1; y++) {
        for (int x = -1; x <= 1; x++) {
            currentNeighborhood[idx++] = texelFetch(currentColor, 
                clamp(coords + ivec2(x, y), ivec2(0), ivec2(width-1, height-1)), 0).rgb;
        }
    }
    
    // 读取运动向量
    vec2 motion = texelFetch(motionVectors, coords, 0).rg;
    
    // 计算历史采样位置
    vec2 historyCoords = (vec2(coords) + motion) / vec2(width, height);
    
    // 有效性检测
    float historyWeight = 1.0;
    
    // 边界检测
    if (any(lessThan(historyCoords, vec2(0.0))) || 
        any(greaterThan(historyCoords, vec2(1.0)))) {
        historyWeight = 0.0;
    }
    
    // 深度检测
    if (historyWeight > 0.0) {
        float depthCurrent = texelFetch(currentDepth, coords, 0).r;
        float depthHistory = texture(historyDepth, historyCoords).r;
        if (abs(depthCurrent - depthHistory) > 0.01) {
            historyWeight *= 0.1;
        }
    }
    
    // 法线检测
    if (historyWeight > 0.0) {
        vec3 normalCurrent = texelFetch(currentNormal, coords, 0).rgb;
        vec3 normalHistory = texture(historyNormal, historyCoords).rgb;
        if (dot(normalCurrent, normalHistory) < 0.9) {
            historyWeight *= 0.1;
        }
    }
    
    // 计算最终颜色
    vec3 finalColor;
    if (historyWeight > 0.5) {
        // 采样历史
        vec3 history = texture(historyColor, historyCoords).rgb;
        
        // 邻域裁剪
        history = clampToNeighborhood(history, currentNeighborhood);
        
        // 混合
        float effectiveBlend = mix(blendFactor, 1.0, 1.0 - historyWeight);
        finalColor = mix(history, current, effectiveBlend);
    } else {
        finalColor = current;
    }
    
    imageStore(outputImage, coords, vec4(finalColor, 1.0));
}
```

### 4.6.3 C++实现框架

```cpp
// TemporalDenoiser.cpp

void TemporalDenoiser::Denoise(
    const std::shared_ptr<Texture>& currentColor,
    const std::shared_ptr<Texture>& motionVectors,
    std::shared_ptr<Texture>& output) {
    
    temporalShader->Use();
    
    // 绑定纹理
    currentColor->Bind(0);
    historyTexture->Bind(1);
    motionVectors->Bind(2);
    currentDepth->Bind(3);
    historyDepth->Bind(4);
    currentNormal->Bind(5);
    historyNormal->Bind(6);
    
    // 设置uniform
    temporalShader->SetInt("width", width);
    temporalShader->SetInt("height", height);
    temporalShader->SetFloat("blendFactor", 0.1f);
    
    // 输出
    output->BindImage(0, 0, GL_WRITE_ONLY);
    
    // 分派
    uint32_t groupsX = (width + 15) / 16;
    uint32_t groupsY = (height + 15) / 16;
    temporalShader->Dispatch(groupsX, groupsY, 1);
    
    ComputeShader::ImageAccessBarrier();
}

void TemporalDenoiser::AdvanceFrame() {
    // 将当前帧的数据复制到历史缓冲区
    // 使用glCopyImageSubData或渲染一个全屏quad
    
    // 复制颜色
    glCopyImageSubData(
        currentColorTexture->GetID(), GL_TEXTURE_2D, 0, 0, 0, 0,
        historyTexture->GetID(), GL_TEXTURE_2D, 0, 0, 0, 0,
        width, height, 1
    );
    
    // 复制深度
    glCopyImageSubData(
        currentDepthTexture->GetID(), GL_TEXTURE_2D, 0, 0, 0, 0,
        historyDepth->GetID(), GL_TEXTURE_2D, 0, 0, 0, 0,
        width, height, 1
    );
    
    // 复制法线
    glCopyImageSubData(
        currentNormalTexture->GetID(), GL_TEXTURE_2D, 0, 0, 0, 0,
        historyNormal->GetID(), GL_TEXTURE_2D, 0, 0, 0, 0,
        width, height, 1
    );
}
```

## 4.9 常见问题

### 问题1：鬼影仍然存在

**原因**：运动向量不准确或有效性检测不完善

**解决**：
1. 检查运动向量计算是否正确
2. 增强深度/法线检测的阈值
3. 使用更激进的邻域裁剪

### 问题2：图像过于模糊

**原因**：历史帧权重过高

**解决**：
```glsl
float blendFactor = 0.15;  // 增大新帧权重
```

### 问题3：快速移动时闪烁

**原因**：历史帧快速失效，频繁重置

**解决**：
- 实现方差估计，动态调整混合权重
- 在历史失效区域增加空域滤波强度

## 4.10 小结
