# 降噪原理与改进

## 本章目标

理解光线追踪降噪的数学原理，掌握从简单滤波到工业级降噪的演进路径。

---

## 2.1 为什么光线追踪会产生噪声？

### 2.1.1 蒙特卡洛积分的直观理解

想象你要计算一个不规则形状的面积。一种方法是把形状切成无数小矩形求和（解析积分），但这通常很难做到。另一种方法是：

```
蒙特卡洛方法：
┌────────────────────────────────────────┐
│  1. 用一个已知面积的框包围形状          │
│  2. 随机撒点                           │
│  3. 数落在形状内的点的比例              │
│  4. 面积 ≈ 框面积 × 比例               │
│                                        │
│    ┌──────────────┐                    │
│    │  •  •        │  10个点中有6个在   │
│    │ • ┌─────┐ •  │  形状内，所以      │
│    │   │ • • │    │  面积 ≈ 框面积×0.6 │
│    │ • │•  • │ •  │                    │
│    │   └─────┘    │                    │
│    │    •    •    │                    │
│    └──────────────┘                    │
└────────────────────────────────────────┘
```

路径追踪做的是同样的事情，只是它在"光线方向"的空间里撒点，估算的是光照积分。

### 2.1.2 方差（噪声）的来源

```glsl
// 路径追踪中的典型代码
vec3 color = vec3(0.0);
for (int i = 0; i < samplesPerPixel; i++) {
    vec3 rayDir = SampleRandomDirection();  // 随机采样
    color += TraceRay(rayDir);              // 追踪光线
}
color /= samplesPerPixel;  // 平均
```

**问题**：每次`SampleRandomDirection`都不同，导致`TraceRay`返回值波动很大。

```
样本数量 vs 噪声水平
═════════════════════

1样本:     ████████████  (噪声极大)
4样本:     ████████      (噪声很大)
16样本:    █████         (噪声明显)
64样本:    ███           (噪声可见)
256样本:   █             (噪声很小)
1024样本: ▌              (几乎无噪声)

数学关系：噪声 ∝ 1/√样本数

要把噪声减半，需要4倍样本！
这是降噪技术存在的意义。
```

## 2.2 滤波的基本原理

### 2.2.1 从简单平均开始

最简单的降噪：把每个像素和它的邻居平均。

```
box_filter_3x3：
┌──────────────────────────────────────┐
│  输入图像（有噪声）                   │
│  ┌───┬───┬───┐                       │
│  │ 5 │ 8 │ 6 │                       │
│  ├───┼───┼───┤   平均后：            │
│  │ 7 │10 │ 9 │   ─────────           │
│  ├───┼───┼───┤   中心像素 = 7.1      │
│  │ 6 │ 7 │ 8 │   (所有9个值的平均)    │
│  └───┴───┴───┘                       │
└──────────────────────────────────────┘
```

**问题**：边缘被模糊了！

```
问题演示：
原图：清晰的边缘         模糊后：边缘被软化
    ██████████              ██████████
    ██████████              ██████████
    ██████████  ───────►    ▓▓▓▓▓▓▓▓▓▓  ← 边缘变灰了
    ░░░░░░░░░░              ▓▓▓▓▓▓▓▓▓▓
    ░░░░░░░░░░              ░░░░░░░░░░
```

### 2.2.2 高斯滤波：距离加权

改进：离中心越远的像素，权重越小。

```
高斯权重分布（σ=1.0）：
┌─────────────────────────────────────┐
│  权重公式：                          │
│  w(x,y) = exp(-(x²+y²)/(2σ²))       │
│                                     │
│  ┌─────────────────────────────┐    │
│  │  0.02  0.08  0.14  0.08  0.02│   │
│  │  0.08  0.30  0.53  0.30  0.08│   │
│  │  0.14  0.53  1.00  0.53  0.14│   │
│  │  0.08  0.30  0.53  0.30  0.08│   │
│  │  0.02  0.08  0.14  0.08  0.02│   │
│  └─────────────────────────────┘    │
│        中心权重最大，边缘权重最小    │
└─────────────────────────────────────┘
```

**问题仍然存在**：边缘还是会被模糊，只是程度轻一些。

### 2.2.3 双边滤波：当前实现

**核心思想**：不仅要考虑距离，还要考虑颜色相似度。

```
双边滤波权重 = 空间权重 × 颜色权重

空间权重：距离越近，权重越大
颜色权重：颜色越相似，权重越大

效果：
┌─────────────────────────────────────────────┐
│  场景：红色墙面上有一个绿色方块              │
│                                             │
│  ┌─────────────────┐                        │
│  │  红红红绿绿绿绿  │                        │
│  │  红红红绿绿绿绿  │   在绿色区域采样时：    │
│  │  红红红绿绿绿绿  │   - 红色邻居：距离近    │
│  │  红红红绿绿绿绿  │     但颜色差异大        │
│  │                 │     → 权重很小          │
│  └─────────────────┘   - 绿色邻居：距离近    │
│                         颜色也相似           │
│                         → 权重正常           │
│                                             │
│  结果：边缘被保留！                          │
└─────────────────────────────────────────────┘
```

**数学公式**：

```
对于输出像素(i,j)：

output(i,j) = Σ w(p,q) × input(p,q) / Σ w(p,q)
              (p,q)∈邻域

其中：
w(p,q) = w_spatial(p,q) × w_color(p,q)

w_spatial = exp(-||p-q||² / 2σ_s²)    # 空间权重
w_color   = exp(-||color_p - color_q||² / 2σ_c²)  # 颜色权重
```

## 2.3 当前实现的问题深入分析

### 2.3.1 问题一：颜色噪声误导

**场景**：场景中有一个表面颜色均匀的墙壁，但路径追踪产生了噪声。

```
理想情况（无噪声）：
┌─────────────────┐
│  0.5  0.5  0.5  │
│  0.5  0.5  0.5  │  双边滤波识别到：
│  0.5  0.5  0.5  │  "所有像素颜色相同"
│  0.5  0.5  0.5  │  → 可以大胆模糊
└─────────────────┘

实际情况（有噪声）：
┌─────────────────┐
│  0.3  0.7  0.4  │
│  0.6  0.5  0.8  │  双边滤波识别到：
│  0.4  0.2  0.6  │  "像素颜色差异很大"
│  0.7  0.5  0.3  │  → 不敢模糊
└─────────────────┘  → 降噪效果差！
```

**根本原因**：双边滤波把"噪声导致的颜色差异"误判为"真实边缘"。

### 2.3.2 问题二：无法区分几何边缘

**场景**：两个相邻物体颜色恰好相似，但几何上是分开的。

```
场景：一个白色球放在白色桌面上

侧视图：
    ╭───╮
   │ 球 │  ← 白色
   ╰─┬─╯
     │桌子│ ← 也是白色

俯视图（颜色图）：
┌─────────────────┐
│  白白白白白白白  │
│  白白白白白白白  │  双边滤波：
│  白白白白白白白  │  "颜色都差不多"
│  白白白白白白白  │  → 会模糊球和桌子的边界！
└─────────────────┘

但如果我们有法线图：
┌─────────────────┐
│  ↑↑↑↑↑↑↑↑↑↑↑↑  │  法线朝上（桌面）
│  ↑↑↑↑↑↑↑↑↑↑↑↑  │
│  ↗↗↗↑↑↑↖↖↖↖↖  │  法线变化（球的边缘）
│  ↗↗↗↗↗↗↖↖↖↖↖  │  法线指向球心方向
└─────────────────┘

法线不同 → 这是几何边缘 → 不应该模糊！
```

### 2.3.3 问题三：单一尺度

当前实现使用固定的9x9核。

```
不同尺度的噪声需要不同大小的滤波核：

小尺度噪声（高频）：
████░░░░████    需要小核（3x3）即可
░░░░████░░░░

大尺度噪声（低频）：
▓▓▓▓░░░░░░▓▓▓▓  需要大核（15x15）
░░░░░░░░░░░░░░  才能有效平滑

当前9x9核的问题：
- 对小尺度噪声：足够
- 对大尺度噪声：不够
- 固定大小：不灵活
```

## 2.4 改进方案概览

### 2.4.1 多特征引导滤波

**核心思想**：利用G-Buffer提供的几何信息指导滤波。

```
可用的G-Buffer特征：
┌─────────────────────────────────────────────┐
│  特征        │  来源        │  作用          │
├─────────────────────────────────────────────┤
│  深度        │  Position    │  区分前后物体  │
│  法线        │  Normal      │  区分几何边界  │
│  材质ID      │  Material    │  区分不同材质  │
│  粗糙度      │  Roughness   │  调整滤波强度  │
└─────────────────────────────────────────────┘

改进的权重计算：
w(p,q) = w_spatial × w_color × w_normal × w_depth

w_normal = exp(-||N_p - N_q||² / 2σ_n²)   # 法线权重
w_depth  = exp(-|D_p - D_q|² / 2σ_d²)     # 深度权重
```

**实现要点**：
1. 从G-Buffer读取法线和深度
2. 修改`denoiser.comp`，添加额外的权重计算
3. 需要传入G-Buffer纹理到降噪着色器

### 2.4.2 A-Trous小波变换：多尺度滤波

**核心思想**：用多个不同大小的核，依次滤波。

```
A-Trous（"with holes"）的含义：

标准3x3核：           A-Trous扩展（步长2）：
┌─┬─┬─┐               ┌─┬─┬─┬─┬─┐
│ ●│ ●│ ●│              │ ●│  │ ●│  │ ●│
├─┼─┼─┤               ├─┼─┼─┼─┼─┤
│ ●│ ●│ ●│    →        │  │  │  │  │
├─┼─┼─┤               ├─┼─┼─┼─┼─┤
│ ●│ ●│ ●│              │ ●│  │ ●│  │ ●│
└─┴─┴─┘               ├─┼─┼─┼─┼─┤
                      │  │  │  │  │
                      ├─┼─┼─┼─┼─┤
                      │ ●│  │ ●│  │ ●│
                      └─┴─┴─┴─┴─┘

效果：用同样的3x3计算量，覆盖5x5的区域！
通过调整步长，可以快速改变滤波尺度。
```

**多尺度流程**：

```
输入噪声图像
     │
     ▼
┌─────────────┐
│ 尺度1（小） │  处理高频噪声
│ 步长=1      │
└─────┬───────┘
      │
      ▼
┌─────────────┐
│ 尺度2（中） │  处理中频噪声
│ 步长=2      │
└─────┬───────┘
      │
      ▼
┌─────────────┐
│ 尺度3（大） │  处理低频噪声
│ 步长=4      │
└─────┬───────┘
      │
      ▼
输出降噪图像
```

### 2.4.3 时域降噪

**核心思想**：利用历史帧的信息，实现更稳定的降噪。

```

```
第一步：添加G-Buffer引导

       ↓ 进一步提升质量
