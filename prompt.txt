# HybridPBR Renderer - AI Development Prompt

## 项目概述
这是一个基于物理的实时渲染引擎，支持混合渲染管线（光栅化 + 光线追踪）。项目使用OpenGL 4.6 + C++17技术栈，旨在结合传统光栅化的实时性能与光线追踪的精确性。

## 当前项目状态
根据代码库结构分析，项目已完成以下工作：
- **基础框架**：完成了Application、Window、Input等核心模块（第1-2周任务）
- **PBR系统**：实现了BRDF、IBL、PBRMaterial等PBR核心组件（第3-5周任务）
- **渲染管线**：建立了完整的光栅化和光线追踪架构，包括GBuffer、DeferredRenderer、BVH、RayTracer等
- **场景管理**：实现了Scene、SceneNode、Transform等场景图结构
- **资源管理**：完成了ModelLoader、ResourceManager等资源加载与管理系统
- **工具类**：提供了MathUtils、Logger等实用工具

## 关键技术亮点

### 1. 混合渲染策略
```cpp
// 每帧决策渲染策略
void RenderFrame() {
    if (useHybrid) {
        raster->RenderGBuffer();      // 光栅化G-Buffer
        raytrace->TraceReflections(); // 光追反射
        compose->BlendResults();      // 结果合成
    } else if (usePureRaytrace) {
        raytrace->PathTrace();        // 纯路径追踪
    } else {
        raster->RenderFull();         // 纯光栅化
    }
}
```
